Differences from Kodiak

AspectKodiak (QCM6490)LeMans (IQ-9075)
First stage / signingTF-A BL2 — single sign (sectools, TZ-TEE)U-Boot SPL — double sign (SWIV + qtestsign)
Boot imageTF-A FIP (BL31+BL32+BL33)SPL_LOAD_FIT boot FIT (BL31+OP-TEE+U-Boot)
Kernel DTBembedded in the UKI (-el2)embedded in the UKI (-el2) — same
U-Boot control DTBmulti-DTB FIT — board auto-detected from SMEM socinfoappended DTB in the boot FIT
Boot sequenceXBL → BL2 → BL31 → OP-TEE → U-Boot → UKIXBL → SPL → BL31 → OP-TEE → U-Boot → Linux

Double signing: LeMans wraps the SPL in an inner SWIV segment (swiv_build_utility.py), then signs the result with qtestsign — two layers, vs Kodiak's single sectools signature.
